03 Projetos

Room Sentinel

GitHub ↗

Python · Streamlit · Supabase (Postgres, Auth, RLS) · Scapy

Plataforma de monitoramento e inventário de infraestrutura de AV, criada para resolver a falta de visibilidade centralizada do status de ~120 equipamentos em ~68 salas de reunião — antes só dava pra saber se algo estava funcionando indo fisicamente em cada sala. Painel único com verificação automática por ping, heurística que evita falsos alarmes, acompanhamento de desgaste de lâmpada de projetor e descoberta automática de porta/switch/VLAN via captura de pacotes CDP/LLDP.

WinHealth

GitHub ↗

PowerShell · WPF/XAML · WMI/CIM · Criptografia AES-256

Kit de diagnóstico, reparo e manutenção preventiva para suporte técnico de TI, rodando via pendrive sem instalação. Detecta o nível de acesso disponível em tempo real — inclusive diagnosticando por que um pendrive está sendo bloqueado — e executa reparos nativos do Windows (DISM, SFC, CHKDSK) com ponto de restauração automático. Mais de 200 testes automatizados em PowerShell puro.
